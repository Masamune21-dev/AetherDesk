Layar Anda, menyeberangi jarak

Sambungkan ke komputer mana pun lewat Device ID dan kata sandi sekali pakai. Tanpa membuka satu port pun di jaringan Anda, dan tanpa perantara yang pernah melihat isi layarnya.

Buat organisasi Panduan penggunaan

Urutan penggunaan

Buat organisasi Wajib lebih dulu. Seluruh perangkat dan pengguna hidup di dalam satu organisasi, dan tanpa itu tidak ada tempat bagi perangkat untuk terdaftar.
Bagikan layar dari perangkat yang akan diakses Perangkat menampilkan Device ID dan kata sandi sesi untuk dibacakan. Kata sandi berganti setiap sesi berakhir, jadi yang sempat bocor tidak lagi berlaku.
Hubungkan dari perangkat Anda Masukkan Device ID dan kata sandi, lalu tunggu persetujuan dari sisi sana. Permintaan tidak pernah diterima diam-diam.

Lewat browser, atau lewat aplikasi

Berbagi layar lewat browser tidak memerlukan pemasangan apa pun, tetapi browser memang tidak dapat menggerakkan mouse atau mengetik di luar halamannya sendiri — itu batas keamanan yang disengaja, bukan kekurangan yang belum diisi.

Agent browser

  • Tanpa pemasangan
  • Melihat satu layar
  • Tidak dapat mengendalikan mouse
  • Tidak dapat mengetik
  • Tidak dapat berpindah monitor
Bagikan lewat browser

Aplikasi Windows

  • Kendali penuh mouse dan papan ketik
  • Berpindah antar monitor
  • Alias dan kata sandi tetap
  • Izinkan sekali, diingat berikutnya
  • Tetap online setelah komputer menyala
